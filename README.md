## 🧭 What I'm about

I'm an AI & ML undergraduate who learns by shipping. My projects sit at the point where machine learning meets real-world needs: privacy-first tooling for everyday AI use, secure ways to share files, voice interfaces that stay under the user's control, and tools that help developers understand unfamiliar code.

## 🚀 Selected work

| Project | What it is | Stack |
|---|---|---|
| 🔐 [**SVX**](https://github.com/Its-Aditya-Singhal/secure-verified-exchange) | Send a file that only the person you choose can open, with post-quantum encryption and sender controls. | Rust, Tauri |
| 🧩 [**Tessera**](https://github.com/Its-Aditya-Singhal/Tessera) | Local-first Chrome extension for ChatGPT, Claude and Gemini: sharpens your prompts, scrubs secrets, and carries context between chats, all on-device. | TypeScript |
| 🎙️ [**Jarvis**](https://github.com/Its-Aditya-Singhal/Jarvis) | Voice-only Mac assistant that answers only to your voice, using speaker verification. Works in English, Hindi and Hinglish. | Python, Gemini API |
| 🔎 [**codebase-archaeologist**](https://github.com/Its-Aditya-Singhal/codebase-archaeologist) | Helps developers understand an unfamiliar codebase using RAG, Git history and relationship-based retrieval. | Python |
| 📊 [**Impact-Echo-Dashboard**](https://github.com/Its-Aditya-Singhal/Impact-Echo-Dashboard) | Donor dashboard for a hackathon donation platform. | Next.js, TypeScript |
